# The pictures of the user manual, and what each shows
# (ADR-draft-keeping-the-manual-and-its-pictures-current).
#
# One picture per line: its name, then what draws it. The name has no
# language: "tasks" is img/<lang>/tasks.png in every language, "icons/shop"
# the language-neutral img/icons/shop.png. What draws it is a file of the
# assets directory (calendarview.js), a top-level function or constant of
# one (app.js#homeView), or a prefix of catalogue keys (key:shop.setup).
#
# A pull request that changes one of these takes the picture again
# (e2e/manual-shots.cjs), or its description says why it need not:
#   Pictures: not needed — <reason>
# style.css changes every picture a little and is named by none; the
# pictures are taken again as a whole when the look changes.
