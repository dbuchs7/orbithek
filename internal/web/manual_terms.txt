# Bold text in the user manuals that is no label of the UI (ADR-0185).
#
# TestManualNamesExistingLabels checks every label a manual names in bold
# against the catalogue of its language. What a manual sets in bold and the
# UI does not show as text is listed here, with the reason:
#
#   <language> <term> — <reason>
#
# The language is a UI language, or "*" for every manual. Case, an ellipsis
# and trailing punctuation do not matter. A term that no manual sets in bold
# any more, or that has become a label of the catalogue, fails
# TestManualTermsAreUsed until its line is removed.

# Keys of the keyboard and of presentation remotes.
* 0 — a key: shows the whole slide again
* B — a key: makes the presentation window black
* F — a key: full screen
* L — a key: the laser pointer
* Enter — a key
* Escape — a key

# The header shows these as symbols or codes, not as words of the catalogue.

de Neun Punkte — the module switcher's symbol, named by its look
en light and dark mode — the switch, named by its two modes; its tooltip names the mode it switches to
de hellen und dunklen Modus — the switch, named by its two modes; its tooltip names the mode it switches to
